# مركز المذاكرة — مشروع React مستقل

منصة مراجعة تفاعلية لأساسيات الشبكات والحاسوب. تشمل ثلاثة بنوك أسئلة، وخريطة مفاهيم للفصول التسعة، ورسومات موجزة للمفاهيم الأساسية، مع دعم العربية والإنجليزية في ملخصات الفصول.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
```

## الرفع إلى ريبو جديد

1. فك ضغط ملف المشروع على جهازك.
2. ارفع **كل محتويات الملف المضغوط** إلى جذر الريبو، بما في ذلك مجلد `.github/`.
3. اجعل اسم الفرع الأساسي `main`، ثم ادفع الملفات.
4. من **Settings → Pages** اختر **GitHub Actions** مصدرًا للنشر.
5. افتح تبويب **Actions** وانتظر نجاح عملية النشر الأولى.

يبني سير العمل الموقع تلقائيًا إلى `dist/` وينشره. لا ترفع ZIP كملف منفرد؛ ارفع محتوياته بعد فك الضغط.

## ربط دومين لاحقًا

أضف الدومين من إعدادات Pages، واضبط سجلات DNS التي يعرضها GitHub. يستخدم Vite مسارات نسبية للأصول لدعم الدومينات المخصصة.

## بنية المشروع

- `src/main.jsx` الواجهة، خريطة الفصول، الخلاصات التفاعلية، واللغة.
- `src/styles.css` تصميم الواجهة والتجاوب مع الشاشات المختلفة.
- `public/banks/` صفحات بنوك الأسئلة المستقلة.
- `.github/workflows/deploy.yml` البناء والنشر الآلي على GitHub Pages.
